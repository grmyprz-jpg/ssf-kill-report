# SSF Kill Report

Projet de suivi des kills des joueurs de la guilde SSF sur Lords Mobile.

## Objectif

- Suivre jusqu'à 100 joueurs.
- Enregistrer automatiquement les kills.
- Synchroniser les données avec Google Sheets.
- Fonctionner uniquement depuis un téléphone Android.
